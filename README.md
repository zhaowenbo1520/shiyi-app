# 拾遗 - 外部记忆助手

> 想到了就记下来，不要让它溜走。

## 这是什么？

拾遗是一个移动端优先的个人助理 Web App。它帮你快速记录想法、任务、购物清单和提醒事项，自动分类整理，每天只展示最重要的 3 件事，减少焦虑感。

适合容易拖延、健忘、想法很多但容易忘记的人。

## 技术栈

- React 18 + Vite 6
- PWA（通过 vite-plugin-pwa）
- localStorage 本地存储
- 纯 CSS（无额外 UI 框架）

## 本地开发

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 预览构建结果
npm run preview
```

## 部署到 Vercel

1. 把代码推送到 GitHub 仓库
2. 登录 [Vercel](https://vercel.com)
3. 点击 "Add New Project" → 选择你的 GitHub 仓库
4. 框架选择 Vite
5. 部署设置保持默认即可
6. 点击 "Deploy"

部署完成后，Vercel 会给你一个 URL（如 `shiyi-app.vercel.app`）。

## 在安卓手机上使用

### 方法 1：直接部署后访问

1. 部署到 Vercel 后，在安卓 Chrome 中打开部署 URL
2. 点击 Chrome 菜单（右上角三个点）
3. 选择 "添加到主屏幕"（Add to Home screen）
4. 确认添加
5. 手机桌面上会出现「拾遗」图标，点击即可像 App 一样使用

### 方法 2：本地预览 + 手机测试

1. 电脑和手机连接同一个 Wi-Fi
2. 在电脑上运行 `npm run dev`
3. 在手机上打开 Chrome，访问电脑的局域网地址（如 `http://192.168.x.x:5173`）
4. 同样可以添加到主屏幕

## 使用说明

### 快速记录

打开 App 后，首页上方有一个输入框。想到什么就直接输入一句话：

- 「明天晚上 8 点提醒我洗衣服」
- 「买鸡蛋、牛奶、纸巾」
- 「有个创意：做一个防拖延 App」
- 「周末整理房间」

点击「先记下来」即可保存。

### 自动分类

系统会根据关键词自动把内容分到对应的分类：

| 关键词 | 分类 |
|--------|------|
| 买、采购、下单、超市、网购、购物 | 🛒 购物 |
| 创意、想法、灵感、点子、选题 | 💡 创意 |
| 提醒、明天、今晚、今天、周末、几点、早上、下午、晚上 | ⏰ 提醒 |
| 其他 | 📋 任务 |

### 今日待办

首页「今天先做这几件」区域最多显示 3 条未完成的任务和提醒，不会把所有事情都堆在眼前。

### 操作

每条记录都可以：

- ✅ **已经完成** — 标记完成
- 📅 **明天再说** — 推迟到明天
- 🏷️ **改分类** — 手动修改分类
- 🗑️ **删除** — 删除记录

### 数据存储

所有数据保存在浏览器的 localStorage 中。清除浏览器缓存会丢失数据，请注意备份。

## 项目结构

```
src/
├── main.jsx                # 入口
├── App.jsx                 # 主组件
├── App.css                 # 样式
├── index.css               # 全局样式
├── components/
│   ├── QuickRecord.jsx     # 快速记录输入区
│   ├── TodayTasks.jsx      # 今日 3 件事
│   ├── ShoppingList.jsx    # 购物清单
│   ├── IdeaBox.jsx         # 创意库
│   ├── CollectionBox.jsx   # 收集箱
│   └── ItemCard.jsx        # 事项卡片（含操作菜单）
└── utils/
    ├── categorize.js       # 自动分类逻辑
    └── storage.js          # localStorage 数据操作
```
